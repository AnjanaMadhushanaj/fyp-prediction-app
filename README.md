# 🏥 FYP: Intelligent Patient Diagnosis System

## 📝 Project Description
This repository contains the codefor an Intelligent Patient Diagnosis System. It is a machine learning-powered web application built using Streamlit. The system allows users to input patient clinical data (such as age, BMI, and symptoms) and provides a real-time, data-driven prediction of disease risk levels using a trained classification model. 

## ✨ Key Features
* **Interactive Data Dashboard:** Explore medical datasets and view live Key Performance Indicators (KPIs).
* **Smart Diagnostic Form:** User-friendly UI to input patient metrics and clinical notes.
* **Real-time Predictions:** Instant risk assessment (High/Low Risk) powered by Machine Learning.
* **Optimized Performance:** Utilizes advanced caching techniques (`@st.cache_data` & `@st.cache_resource`) for lightning-fast model inference and data loading.

## 🛠️ Technology Stack
* **Framework:** Streamlit (Python)
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (or specified model)
* **Deployment:** Streamlit Community Cloud
